# Brand assets

The mark is a round table: a team seated around one table. The ink seats are agents and the orange seat is the human working with them.

| File | Use |
| --- | --- |
| `icon.svg`, `icon-dark.svg` | The mark alone, for light and dark backgrounds |
| `logo.svg`, `logo-dark.svg` | The mark with the wordmark, for light and dark backgrounds |
| `icon-512.png`, `favicon-32.png` | Raster icons |
| `logo-256h.png`, `logo-dark-256h.png` | Raster logos, 256 px high |
| `avatar-1024.png` | Square avatar on a light tile (organization and app avatars) |
| `social-1280x640.png` | Repository social preview |

Colours: ink `#1F2A44` for the table, the agents and the wordmark (white on dark backgrounds), human orange `#F26B3A`, background `#F6F5F1`.

The wordmark is set in Space Grotesk Bold (SIL Open Font License 1.1) and converted to outlines, so the SVGs need no font.
